# React Reference Implementation 🧩

A sandbox for live coding sessions and technical interviews, demonstrating best practices in modern React development.

### Concepts Demonstrated
- **State Management:** Clean use of Hooks and local/global state patterns.
- **Component Architecture:** Separation of concerns between UI and business logic.
- **TypeScript:** Strong typing for props, events, and API data.
- **Best Practices:** Focus on readability, performance, and maintainable code structure.

### Why this exists
I use this repository as a baseline for discussing technical trade-offs and architectural decisions during technical interviews and pair programming sessions.
